# Abramenko Studio — Telegram demo

Демо сохраняет aiogram 3.x и существующую архитектуру проекта. Заявки хранятся persist-first в SQLite/PostgreSQL через общий async DB adapter (`demo_requests`) со статусом `pending_confirmation` и отдельным статусом/ошибкой уведомления. Telegram-уведомление отправляется только после сохранения. Если `ADMIN_CHAT_ID` пуст или Telegram недоступен, заявка остаётся в БД, а бот честно сообщает, что уведомление не ушло.

Каталог и филиалы взяты только из knowledge base. Цены, адреса и график не выдумываются.

## Локальный запуск

1. Python 3.10+.
2. `python -m venv .venv`
3. Активировать окружение.
4. `pip install -r requirements.txt -r requirements-test.txt`
5. Скопировать `.env.example` в `.env` и задать `BOT_TOKEN`, `ADMIN_CHAT_ID` и при необходимости `DB_PATH=./data/nailshop.db`.
6. `python bot.py`

Тесты: `python -m pytest`. Ручные сценарии описаны в [TEST_DIALOGS.md](TEST_DIALOGS.md). При сбое уведомления заявка сохраняется и получает кнопку «Повторить отправку»; повтор разрешён только владельцу Telegram и безопасно блокируется при параллельной попытке.

## Порядок записи

Обычная запись: услуга → филиал → дата (ДД.ММ.ГГГГ) → время → имя → телефон → мастер (опционально) → подтверждение.

Для окрашивания после опционального мастера дополнительно запрашиваются длина волос → желаемый результат → последнее окрашивание → готовность прислать фото → подтверждение. Бот не ставит диагноз, не называет цену и не обещает результат.

Заявки модели, вакансии и курса валидируют телефон; модели и вакансии также валидируют филиал. Перед сохранением показывается подтверждение с возможностью заполнить форму заново.
